Our controls are:
-Move (integer)
-Turn (left, right)
-Repeat (integer) times
	(repeated command)
-RepeatUntil (GridEdge, WallAhead)
	(repeated command)

You can load an example grid by navigating to the file MSO\MSO\examples\grid.txt
Example Commands are selected at the Top left corner, but you can also just write your own list of commands using the controls listed above.
